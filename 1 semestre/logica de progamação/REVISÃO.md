Algoritmo
	sequencia de passos bem definidas para resolver um problema
Sequencias:
	Logica
		ordem correta das instruções para alcançar um objetivo
	Fluxograma:
		representação logica com simbolos
	pseudocodigo:
		algoritmo em linguagem natural ou semiformatado
		sintaxe facil 
variaveis:
	inteiro
	Real
	caractere
	cadeia
	logico
memoria:
	algo temporario guardado em uma memoria
comandos de entradas/saidas:
	Saida:
		exibe informações para o usuario:
		ex: escreva("Ola mundo!")
	Entrada:
	permita que o usuario forneça dados ao usuario:
		ex:leia(idade)
