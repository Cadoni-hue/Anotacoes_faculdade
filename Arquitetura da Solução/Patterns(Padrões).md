Escala Micro e Macro:
	Macro:
		Decide a estrutura fundamental do projeto
	Micro:
		Resolve problemas especificos de design dentro de um componente ou classe
Patterns de projeto:
	Singleton:
			Garante que uma classe tenha uma unica instancia em todo os sistema e fornece um ponto de acesso global
		Adapter:
			Funciona como tradutor, para adaptar uma api que envia dados em json a enviar dados em xml
		Observer:
			permite que varios objetos (observadores) sejam notificados mesmo eles nao estando "grudado"
UML:
	Diagrama de Competencia:
		Focado no macro, ele mostra como os grandes blocos se conectam dentro do sistema, bom para visualizar um padrão de objeto
	Diagrama de sequencia:
		Focado na visão dinamica e detalhada, mostra os componentes "conversando " entre si
		bom para visualizar padrao de projeto
