Metodos de envio
	GET
			sao enviados na Url (visiveis para usuarios)
			usada para buscar filtros
			nao é seguro para guardar senhas
	Post
			sao enviados no corpo da requisição(nao visiveis na url)
			envios mais seguros, recomendado para usar em forms
oque acontece depois:
	os dados enviados vao para o backend, onde os dados podem ser processados e salvo no banco de dados
